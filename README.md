# 🌍 Earthquake Visualization
![image](https://github.com/YilingSuun/Earthquake-Visualization/blob/main/EarthquakeVisualization.png)

An interactive 3D visualization of earthquakes on both a **globe** and a **flat map**, built with **TypeScript** and **GopherGfx**.  
This project allows users to morph seamlessly between a 3D Earth sphere and a 2D map projection while displaying earthquakes that occurred within the last year.
 
> Note: 1. This repository hosts a **GitHub Pages site**, which consists only of the files in the `dist` folder.
> 
> 2. The `dist` folder contains the **official build** generated by running `npm run build` on the source code.
> 
> 3. The JavaScript in this folder has been obfuscated and is not human-readable.  
---

## ✨ Features

- 🌐 **Dual View Modes** — Switch between a textured globe and a flat map.
  ![image](https://github.com/YilingSuun/Earthquake-Visualization/blob/main/EarthquakeMap.png)
- 🌋 **Dynamic Earthquake Markers** — Display earthquakes by location, color, and size based on magnitude.  
- 🔄 **Smooth Morphing Animation** — The Earth and earthquake markers morph between globe and map layouts.  
- 🕒 **Time-Based Filtering** — Only earthquakes within one simulated year of the current visualization time are shown.  
- 🌀 *(Additional)* Animated Earth rotation, axial tilt, and marker fade-out effects.

## ⚙️ Build and Run Locally

To build and run the game locally, you need the **source code**.  
The `dist` folder alone cannot be rebuilt or edited, as it only contains the compiled output.
The source code of the project is also stored in a git repository, but it is private. I'm just writing here about its usage.

### Requirements
- [Node.js](https://nodejs.org/) and npm installed
- [GopherGfx](https://github.com/djanderson07/GopherGfx) library

### Installation
Here's some code you can use on the command line:

1. Clone the repository
```bash
git clone https://github.com/YilingSuun/Earthquake-Visualization.git
```

2. Enter your directory
```bash
cd YilingSuun/L/Earthquake-Visualization
```

3. install dependencies
```bash
npm install
```
