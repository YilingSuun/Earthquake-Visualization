# 🌍 Earthquake Visualization

An interactive 3D visualization of earthquakes on both a **globe** and a **flat map**, built with **TypeScript** and **GopherGfx**.  
This project allows users to morph seamlessly between a 3D Earth sphere and a 2D map projection while displaying earthquakes that occurred within the last year.

---

## ✨ Features

- 🌐 **Dual View Modes** — Switch between a textured globe and a flat map.  
- 🌋 **Dynamic Earthquake Markers** — Display earthquakes by location, color, and size based on magnitude.  
- 🔄 **Smooth Morphing Animation** — The Earth and earthquake markers morph between globe and map layouts.  
- 🕒 **Time-Based Filtering** — Only earthquakes within one simulated year of the current visualization time are shown.  
- 🌀 *(Additional)* Animated Earth rotation, axial tilt, and marker fade-out effects.
